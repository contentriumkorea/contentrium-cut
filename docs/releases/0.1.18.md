# Contentrium CUT

녹음 방식을 바꿔도 같은 시퀀스의 보호 카메라 역할, 화자 이름, 오디오 스트림·채널, 교정 구간, 수동 편집 구간, 싱크 설정과 시작·예비 카메라를 보존합니다. 트랙 설정 화면을 다시 생성하지 않아 입력 원문이 초기화되지 않습니다.

처음 연결한 시퀀스에서 마이크를 선택하지 않았다면 개별 녹음은 처음 두 오디오 트랙, 혼합 녹음은 첫 트랙을 기본 선택합니다. 사용자가 직접 선택했거나 저장 설정을 복구했다면 선택을 유지합니다. 화자 분석과 모드에 종속된 카메라 연결은 다시 설정하도록 초기화하며, 같은 녹음 방식 버튼을 다시 눌러도 기존 분석은 유지합니다.

전환은 로컬 설정에 즉시 반영하고 최신 모델 상태를 확인합니다. 작업·복구·업데이트 잠금과 업데이트 클릭 즉시 작업 중단·절차 시작을 유지합니다. 파일 교체는 실제 작업 종료 및 정상 Premiere 종료 뒤에만 진행합니다.

전체 회귀·독립 리뷰·패키지 실행·공개 업데이트 서명/실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치는 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
