# Contentrium CUT

편집안을 만들 때의 컷 설정·카메라 연결·수동 구간을 결과와 연결합니다. 서버 응답을 기다리는 동안 다른 값으로 바뀌면 이전 결과를 사용하지 않으며, 적용 요청 전과 편집 허가를 받은 뒤 실제 Premiere 편집 진입 직전에도 같은 입력인지 확인합니다.

입력이 바뀌면 이전 컷 목록·타임라인을 지우고 편집안을 다시 만들도록 안내합니다. 완료한 화자 분석·교정은 유지하며, 카메라 연결과 수동 구간의 입력·삭제도 표시 무효화와 설정 자동 저장에 반영합니다. 동등한 숫자 표기나 계획에 쓰지 않는 설정은 입력 비교에서 제외합니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작과 기존 복구 기록 보존은 유지합니다.

실제 패널 핸들러·전체 회귀·독립 소스 검수·패키지 실행·공개 업데이트 서명과 다운로드 해시를 검증합니다. 컴퓨터유즈·PC 재설치는 수행하지 않았습니다. 실제 Premiere/UXP 화면·편집·기존 설치 전환·Community-1 품질은 미검증입니다.
