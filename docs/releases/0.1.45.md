# Contentrium CUT

설치 복구 버튼의 중복 요청과 이전 응답이 새 안내·연결 상태를 덮는 문제를 개선했습니다.

- 복구 중에는 버튼과 안내에 진행 상태를 표시합니다. 추가 복구·편집·업데이트 확인·자동 설정 저장을 잠그고, 기존 즉시 업데이트·중단 경로를 지연하지 않습니다.
- 실제 편집·재생·분석·파일 확인이 진행 중이거나 연결 준비가 끝나지 않으면 복구를 시작하지 않습니다. 복구가 더 필요한 상태를 완료로 표시하지 않습니다.
- 복구와 후속 상태 조회가 같은 요청·연결·중단 상태에 속할 때만 반영합니다. 새 안내를 보존하면서 현재 인증·패널 충돌은 안전하게 처리하고, 일반 실패에는 재시도 안내를 제공합니다.

Node529개·Python496개·독립580개 시나리오·패널420개를 통과했습니다. 독립 리뷰·패키지 실행·공개 발견·서명·실제 다운로드 해시 검증을 포함한 배포 절차를 적용합니다.

실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 품질은 미검증이며 사용자 설치를 변경하지 않았습니다. 파일 교체는 실제 작업 종료와 Premiere 정상 종료 뒤 진행합니다. 최상단 개별 영상 컷·원본·오디오·별도 자막 트랙을 보존하고 로고·추가 그래픽에 관여하지 않습니다. 중단 작업 기록 확인·이미 발행한 API rollback·connection 물리 전송의 취소는 후속 검증 대상입니다.
