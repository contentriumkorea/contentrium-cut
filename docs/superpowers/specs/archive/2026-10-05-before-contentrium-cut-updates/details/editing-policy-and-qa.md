# 화자 중심 컷 편집 정책과 검증 계약

2026-10-05 · 구현 전 상세 설계 · [전체 설계](../2026-10-05-premiere-speaker-cut-design.md)

같은 분석 결과·매핑·설정은 같은 편집 계획을 만든다. 임계값과 품질 목표는 **검수 전 제안값**이며 실측 성능이나 현재 기능을 뜻하지 않는다.

## 1. 절대 보존 조건과 입력

- 원본 미디어·시퀀스를 보존하고 별도 결과 시퀀스를 만든다. 분석 범위 밖도 보존한다.
- 화면 컷만 바꾼다. 연속 오디오의 소스 In/Out·배치·채널·볼륨·효과·음소거와 기존 공백을 보존한다. 침묵 삭제·영상 컷에 따른 오디오 자동 분할은 하지 않는다.
- 사람–음성 ID–카메라 연결은 사용자가 처음 확인한다. 분리 마이크의 채널 이름이나 혼합 음원의 임시 화자 번호를 실명으로 추정하지 않는다. 한 사람에게 같은 카메라를 연결하거나 여러 사람이 한 카메라를 공유할 수 있다.
- 카메라를 바꿀 때 영상·오디오를 자동으로 연결 해제하거나 원본 링크를 수정하지 않는다. 선택된 카메라만 표시하면서 오디오와 링크 상태를 보존할 수 없는 호스트 구성은 적용 전 차단한다.
- 두 녹음 방식은 공통 화자별 발화·겹침·판별 불가 입력과 동일 정책을 쓴다. 짧은 끼어들기는 길이 기준이다. “네”, 맞장구, 웃음의 의미를 이해했다고 표시하지 않는다.

매핑은 카메라 ID, 대상 인물 집합, 기본/전체/투샷 역할, 명시적 예비 카메라 목록·순위, 클립별 유효 구간을 포함한다. 전체/투샷의 등장 인물은 사용자가 확인한다. 두 사람 투샷은 세 사람 겹침에 부적합하다. 화자 연결이나 시작 화면이 미확정이면 적용을 차단한다.

## 2. 시간축과 임계값

| 설정 | 최초 제안값 | 의미와 경계 |
| --- | --- | --- |
| 최소 화면 유지 M | 2.0초 | 일반 전환은 마지막 실제 화면 전환 후 M 이상 경과해야 허용 |
| 짧은 경쟁 발화 B | 켜짐 / 0.6초 | 다른 사람의 연속 발화가 B 이하이면 새 단독 화면을 만들지 않음 |
| 지속 겹침 O | 0.8초 | 두 명 이상으로 확인된 동시 발화가 O 이상 연속되면 겹침 화면 후보 |

`짧은 반응에 화면 유지`를 끄면 B 억제만 건너뛴다. 짧은 단독 발화도 전환 후보가 되지만 최소 길이·겹침·불확실·커버리지 규칙은 유지한다. 설정 변경은 음성 분석을 재사용해 계획만 재계산한다.

원시 경계 → 시퀀스 시간 → 프레임 정렬 → 길이 판정 → 화면 선택 순이다. 구간은 정수 프레임의 `[시작, 끝)`이며 끝 프레임은 다음 구간에 속한다. 중복·누락을 허용하지 않는다.

FPS는 분수 `p/q`다. 샘플 위치·검증된 싱크 오프셋의 절대 시퀀스 시간을 한 번만 가장 가까운 프레임으로 변환한다. 정확한 반 프레임은 뒤쪽이다. 공유 시작·종료 경계는 같은 정수를 재사용하고 29.97 같은 근사값을 누적하지 않는다. 원시 경계·정렬 오차를 보존한다.

설정값은 `올림(초 × p/q)` 프레임으로 바꿔 판정하며 실제 적용 길이도 표시한다. 30fps에서는 M=60, B=18, O=24프레임이다. 정렬 후 0프레임인 자동 분석 구간은 화면을 만들지 않고 기록에 남긴다. 사용자 고정 구간이 0프레임이면 입력 오류로 거부한다. 촬영 소스의 FPS가 달라도 정책의 경계는 결과 시퀀스 FPS를 따른다.

동일 화자의 닿거나 겹치는 발화는 합치되 침묵을 건너 합치지 않는다. 지속 겹침은 확인된 활성 화자 두 명 이상인 연속 구간이다. 단독 발화·판별 불가 한 프레임이라도 끼면 별개 구간으로 나눈다.

## 3. 결정 순서와 충돌 해결

편집 계획기는 발화 시작·종료, 영상 커버리지 시작·종료, 사용자 고정 구간 경계, 최소 길이 만료 시점, 분석 범위 끝을 모두 사건 경계로 사용한다. 같은 프레임의 종료를 반영한 뒤 그 프레임에 시작하는 상태를 계산하고, 아래 순서로 한 번만 결정한다.

| 순위 | 조건 | 반드시 수행할 판단 |
| --- | --- | --- |
| 0 | 입력·시간 매핑·오디오 보존·영상 커버리지 검증 불가 | 계획의 적용을 차단. 최소 길이나 사용자 고정으로 무시 불가 |
| 1 | 유효한 사용자 고정 화면 구간 | 지정 카메라를 정확한 시작·끝에 적용. 최소 길이와 화자 정책보다 우선 |
| 2 | 판별 불가 화자/구간이 현재 존재 | 기존 카메라 유지, 검토 표시. 최소 길이 만료만으로 전환하지 않음 |
| 3 | 지속 겹침 구간 | 적합한 전체/투샷으로 겹침 시작점에 전환. 진입은 최소 길이 예외 |
| 4 | 다른 화자의 짧은 경쟁 발화 | 기존 화면 유지. 일반 단독 전환 후보를 만들지 않음 |
| 5 | 확인된 단독 화자의 충분한 발화 | 해당 사람의 기본 카메라 후보를 만들고 최소 길이 적용 |
| 6 | 침묵 또는 지속 기준 미만의 겹침 | 기존 화면 유지. 침묵 종료 자체는 전환 이유가 아님 |

순위 0의 커버리지 검사는 선택한 카메라가 바뀔 때마다 다시 한다. 자동 후보의 영상 공백은 5절의 대체 순서로 해결할 수 있지만 유효한 대체가 없으면 차단한다. 사용자가 고정한 카메라의 공백은 지정 의도와 충돌하므로 대체하지 않고 차단한다.

최소 길이는 소프트 제약이다. 사용자 고정 경계, 현재 영상의 종료로 필요한 대체, 지속 겹침 진입만 이를 깨는 전환을 허용한다. 예외마다 이유를 기록한다. 분석 범위의 첫·마지막 화면은 범위 경계 때문에 M보다 짧을 수 있다. 길이를 맞추려고 범위를 늘리거나 마지막 발화를 잘라내지 않는다.

일반 단독 후보의 시작점이 너무 빠르면 허용 시점을 `현재 화면 시작 + M`으로 잡는다. **그때도 같은 후보가 유효할 때만** 전환한다. 그 전에 발화가 끝나거나 불확실·침묵·다른 후보가 생기면 대기 후보를 폐기한다. 끝난 사람에게 예약 컷을 만들지 않는다. 분석 구간 분할은 최소 길이 타이머를 초기화하지 않는다. 희망 카메라의 공백만으로 최소 길이를 깨지 않으며, 현재 영상이 유효하면 일반 전환 허용 시점까지 유지한다.

두 화자가 같은 카메라에 연결되어 있으면 화자 변경만 기록하고 컷을 추가하지 않는다. 인접 구간의 카메라·소스·소스 시간 진행·보존할 효과가 연속이면 합친다. 같은 카메라라도 별도 녹화 파일 경계는 필요한 소스 연결을 유지한다. “화자 구간 수”와 “생성 컷 수”가 같을 필요는 없다.

## 4. 시작·종료·겹침의 구체 규칙

시작이 확인된 단독 발화이면 길이 억제 없이 해당 카메라를 쓴다. 침묵·판별 불가·짧은 겹침이면 지정 시작 화면, 지속 겹침이면 적합한 전체/투샷을 쓴다. 커버리지는 모두 검사하며 분석 범위 이전의 화면 유지 길이는 최소 길이에 합산하지 않는다.

짧음은 해당 사람의 전체 연속 발화 길이로 판단하며 짧은 겹침·단독 발화 모두 억제한다. B 초과는 일반 후보다. 반복된 짧은 발화를 합치지 않는다. 중요한 짧은 답변이 화면에서 빠질 수 있으므로 구간 수정을 제공한다.

전체 자료에서 O 이상 겹침을 확인해 **겹침 시작점**에 전환한다. O초 확인 시간이 컷 지연이 되지 않는다. 확정 종료점에 남은 단독 화자는 복귀 후보지만 전체/투샷의 M을 따른다. 그 전에 발화가 끝나면 후보를 폐기하고 침묵이면 화면을 유지한다.

적합한 전체/투샷이 없으면 현재 화면 유지와 겹침 검토 표시를 한다. 음량으로 사람을 고르지 않는다. 겹침 참여자가 바뀌면 같은 프레임에 투샷 적합성을 재검사한다. 동률은 지정 순위, 이후 고정 카메라 ID 순이다.

유지는 정상 디코딩·분석된 국소 판별 불가 구간에만 허용한다. 채널 충돌·국소 인물 연결 불명확 사유를 기록하고 직전 사람으로 덮지 않는다. 종료점에 실제 상태를 재평가한다. 확정 sessionSpeakerId 미매핑은 `SPEAKER_MAPPING_REQUIRED`, 오디오 결손·모델 실패는 하드 차단이며 침묵·unknown으로 위장하지 않는다. 임의 확률을 만들지 않는다.

## 5. 영상 가용성과 대체

가용 영상은 소스가 온라인이고 지원 시간 매핑으로 실제 한 프레임 전체를 읽을 수 있어야 한다. 파일 존재만으로 충분하지 않다. 화면 유지는 다음 소스 프레임의 정상 재생이며 마지막 프레임 정지나 클립 늘이기가 아니다.

자동 선택 카메라에 공백이 있으면 ① 허용한 가용 WIDE ② 현재 재생 카메라 ③ 사용자가 명시적으로 지정한 예비 카메라 순으로 검사한다. 동순위는 지정 순서, 이후 고정 카메라 ID 순이다. 원하는 화자를 담지 못하는 대체는 `영상 공백 대체` 검토 사유를 남긴다. 이전 사용 이력만으로 예비 자격을 부여하거나 미지정 카메라를 선택하지 않는다.

대체 영상이 끝나면 그 경계에서 다시 선택하며 최소 길이 예외를 허용한다. 원래 영상 복귀는 화자가 여전히 유효할 때 일반 전환 후보가 되고 최소 길이를 따른다. 허용 후보가 하나도 없는 단 한 프레임이라도 전체 적용을 차단하고 시간·카메라별 누락을 표시한다.

“검은 화면 없음”의 검증 대상은 계획이 만든 빈 구간·잘못된 소스 범위다. 원본에 이미 찍힌 검은 프레임까지 임의로 다른 화면으로 바꾸지는 않는다. 원본의 검은 프레임, 가림, 초점 문제는 영상 품질 검토와 구분한다.

## 6. 수동 구간 수정 계약

사용자는 구간별 사람 연결을 수정하거나 카메라를 고정할 수 있다. 사람 수정은 분석 입력 수정본으로 저장하고 재계산한다. 화면 고정은 정책보다 우선한다. 원시 분석을 보존하고 스냅샷, 수정 전후 값, 구간, 시점을 기록한다.

고정은 프레임 정렬 후 범위 내 포함·양의 길이·카메라·전 구간 커버리지를 검사하며 자동으로 잘라 맞추지 않는다. 같은 카메라의 중복 고정은 합치고 다른 카메라끼리 겹치면 적용을 차단한다. 저장 순서로 덮어쓰지 않는다.

고정 종료점은 그때의 화자 상태로 복귀하며 최소 길이 예외를 기록한다. 고정 삭제는 나머지 수정과 분석에서 재계산한다. Premiere에서 직접 수정한 결과는 덮지 않고 상위 문서의 변경 감지·새 결과 생성 계약을 따른다.

## 7. 30fps, 0–20초 계산 예제

범위는 `[0,600)`, M=60, B=18, O=24프레임이다. 시작 카메라는 W. A→CA, B→CB이며 W는 두 사람이 포함된 전체 화면이다. CA는 `[0,360)` 및 `[420,600)`에만 존재하고 CB·W는 `[0,600)` 전체에서 가용하다. 오디오 전체와 침묵은 그대로 둔다.

| 분석 입력 | 초 구간 | 프레임 구간 |
| --- | --- | --- |
| A 발화 | 0–5 / 8–9.2 / 12–16 / 17.3–20 | [0,150) / [240,276) / [360,480) / [519,600) |
| B 발화 | 2.4–2.8 / 5–8.8 / 10–12 / 16.5–17.3 | [72,84) / [150,264) / [300,360) / [495,519) |
| 판별 불가 | 16–16.5 | [480,495) |
| 침묵 | 9.2–10 | [276,300) |

| 기대 화면 | 프레임·초 구간 | 결정 근거 |
| --- | --- | --- |
| CA | [0,150), 0–5초 | 시작 단독 A. B의 [72,84)는 12프레임으로 짧아 유지 |
| CB | [150,240), 5–8초 | B 발화가 충분하고 CA를 150프레임 유지했으므로 시작점 전환 |
| W | [240,300), 8–10초 | [240,264) 겹침이 정확히 24프레임이므로 240에 진입. 264의 A 복귀는 W 최소 길이 만료 300까지 대기해야 하나 A가 276에 끝나 취소. 이후 침묵 유지 |
| CB | [300,360), 10–12초 | B 단독이며 W를 60프레임 유지해 즉시 전환 |
| W | [360,420), 12–14초 | CB의 최소 길이 충족. A로 바꿀 때 CA 녹화 공백이므로 전체 화면 대체 및 검토 표시 |
| CA | [420,495), 14–16.5초 | CA 영상 복귀, A 발화 유효, W 최소 60프레임 충족. 480–495 판별 불가는 CA 유지 및 검토 표시 |

| CA | [555,600), 18.5–20초 | 555에도 A가 발화 중이므로 전환. 마지막 45프레임은 범위 종료 예외 |

기대 전환 프레임은 **150, 240, 300, 360, 420, 495, 555**이며 72·84·264·276·480·519에는 컷이 없다. 발화·검토 경계는 별도 기록한다. 8구간의 합은 600프레임, 영상과 오디오 끝은 20초다.

## 9. 오류 분리와 출시 판정

① 사람의 화자 라벨 대비 **분석 오류** ② 정답 입력의 기대 화면 대비 **정책 오류** ③ 확정 계획 대비 Premiere의 **적용 오류**를 분리한다. 화자 오인식을 임계값 조정으로 해결했다고 처리하거나 올바른 분석의 잘못된 컷을 모델 탓으로 돌리지 않는다.

검증 자료 제안은 한국어 세션 12개 이상, 방식별 6개 이상, 합계 6시간 이상이다. 2–4명, 짧은 답변, 겹침, 침묵, 누음, 잡음, 녹화 중단과 방식별 60분 이상 연속 자료를 포함한다. 튜닝·평가 자료를 분리하고 빠진 조건은 미검증으로 남긴다.

실행 전 두 검수자가 독립 라벨을 만들고 허용 화면·전환 범위를 합의한다. 등급 제안은 발화 중 화자 집합 라벨 일치 95% 이상, 클리핑·음성 가림·강한 누음 표시의 합집합이 발화 시간 1% 이하인 세션을 `깨끗함`, 나머지를 `어려움`으로 정한다. 사유·미합의 분량을 보고하고 모델 점수로 등급을 바꾸지 않는다.

| 출시 관문 | 제안 합격 조건 및 측정 방법 |
| --- | --- |
| 결정 정책 | 정답 입력 기반 경계·예외·충돌 자료 100% 일치. 불일치 1건도 수정 후 재검증 |
| 호스트 적용 | 계획 대비 실제 컷·소스 프레임 오차 0, 빈 틈 0, 범위 길이 변화 0. 60분 이상 끝에서도 누적 이동 0프레임 |
| 보존 | 원본 내용 변경 0, 오디오 배치·채널·설정 변화 0, 지원 효과 손실 0. 실제 재생에서 오디오 연속성 확인 |
| 분석 품질 목표 | 명확한 단독 발화 시간 중 올바른 사람 배정 비율: 깨끗한 자료 90% 이상, 어려운 자료 85% 이상. 미배정도 오답에 포함 |
| 겹침 품질 목표 | 검수자가 확인한 지속 겹침에 대해 구간 시간 기준 정밀도·재현율 각각 80% 이상. 과다 겹침과 누락을 따로 보고 |
| 편집 사용성 목표 | 깨끗한 자료의 평가 가능 시간 중 허용 카메라 일치 90% 이상. 수동 보정 소요시간은 동일 자료의 수동 편집 기준 대비 중앙값 50% 이하 |
| 검토 부담 목표 | 깨끗한 자료의 검토 표시 시간 15% 이하를 지향. 목표 달성을 위해 불확실 표시를 숨기거나 오류를 정답으로 바꾸지 않음 |

시간은 고정 `[S,E)`의 정렬 프레임으로 집계한다. 화자 배정 분모는 확정 단독 발화 전부(M·B 억제 포함), 정답은 같은 단일 ID다. 겹침 정밀도=교집합/예측, 재현율=교집합/정답이며 동일 O를 적용한다. 분모 0은 N/A다. 화면 분모는 허용 화면 라벨 전체(침묵·정책 유지 포함), 검토 부담은 사유별 중복을 뺀 구간 합집합/[S,E)다. 사전 미합의 라벨만 해당 지표에서 제외하고 제외량·세션별 점수·합산 시간을 보고한다.

수치는 **미달성 목표**다. 방식·잡음·세션별 최악 사례도 보고한다. 장기 화자 뒤바뀜·미검출 공백·원본 변경·오디오 단절은 출시 차단이다. 기준 미달은 지원 제한이며 한 입력 방식의 통과로 전체 완료를 선언하지 않는다.

증거는 입력·매핑·설정·정답 버전, 원시/정렬 경계, 계획/실제 컷, 원본·오디오 보존, 검토 사유, Premiere 재생이다. 시뮬레이션으로 실제 연동 검증을 대체하지 않는다.
