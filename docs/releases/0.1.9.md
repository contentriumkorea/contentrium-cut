# Contentrium CUT

싱크 소스 행에서 채널·오디오 스트림 입력 오류를 바로 표시합니다. 잘못된 값, 소스 2개 미만 선택, 선택에서 제외된 기준 소스는 싱크 분석과 적용 전에 차단하고 수정 방법을 안내합니다. 자동·수동·타임코드 방식에 모두 적용하며 실제 파일의 스트림·채널 존재 여부는 분석 엔진이 계속 검사합니다.

입력 중에도 이전 싱크 결과와 적용 가능 상태를 지웁니다. 설정 저장·복구 및 타임라인 자동 갱신에서는 빈 값과 미선택 행의 원시 값을 유지하고 기존 숫자 설정도 읽습니다. 화자 분석·컷 편집은 싱크 입력 오류로 막지 않으며 업데이트 클릭 즉시 작업 차단은 유지합니다.

패널 핸들러·전체 회귀·독립 소스 검수, 패키지 실행과 공개 업데이트 서명·다운로드 해시를 검증합니다. 컴퓨터유즈·PC 재설치는 수행하지 않았으며 실제 Premiere/UXP 화면·편집·기존 설치 전환·Community-1 품질은 미검증입니다.
