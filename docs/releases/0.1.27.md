# Contentrium CUT

자동 시퀀스 갱신이나 수동 재조회 도중 업데이트를 누르면 즉시 업데이트 절차를 시작하고 늦게 도착한 타임라인·시퀀스 등록·저장 설정 응답은 화면에 반영하지 않습니다. 기존 연결·트랙·분석·안내·예약된 설정 저장을 보존합니다.

연결·작업 세대·녹음 모드·분석 상태가 달라졌을 때도 이전 응답을 무시합니다. 새 시퀀스의 저장 설정 조회를 완료한 뒤 화면을 함께 반영하고, 오래된 조회가 새 조회의 작업 상태를 해제하지 않도록 했습니다. 정상 자동 갱신·수동 재조회·초기 연결·저장 설정 복원·같은 시퀀스의 원시 입력과 자동 저장을 유지합니다.

전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명 및 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치를 하지 않습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
