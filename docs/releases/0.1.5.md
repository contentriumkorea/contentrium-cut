# Contentrium CUT

- 설정에서 업데이트 사용 불가, 호환 불가, 조회·검증 실패를 구별하고 다음 조치를 안내합니다. 서버 요청 제한이 있으면 재조회까지 남은 최소 대기를 표시합니다.
- 파일 교체, 설치 검증, 이전 버전 복구와 설치 복구 단계를 한국어로 표시합니다. 외부 오류 상세나 로컬 경로 대신 제한된 오류 코드만 표시합니다.
- 취소·실패·복구 뒤 다시 업데이트를 누르면 이전 결과보다 새 시작 요청을 먼저 표시합니다. 조회 중에도 검증된 업데이트 후보를 즉시 실행할 수 있습니다.

업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작을 유지합니다. 파일 교체는 실제 작업 종료와 Premiere 정상 종료 뒤 진행합니다. 단일 Premiere 패널, 최상단의 수정 가능한 개별 컷, 원본·오디오·별도 자막 트랙 보존 계약을 유지합니다.

사용자 PC에 재설치하지 않았습니다. 실제 새 UXP 화면·Premiere 편집·기존 설치 전환 및 Community-1 실음성 품질은 아직 미검증입니다. 이전 취소 시험의 간헐 실패는 이번 단독 64회에서는 재현되지 않았고 원인은 미확정입니다. [반복 개선 기록](https://github.com/contentriumkorea/contentrium-cut/blob/main/docs/qa/continuous-improvement.md)에서 검증 범위를 확인할 수 있습니다.
