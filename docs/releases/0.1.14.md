# Contentrium CUT

접힌 수동 구간 영역 밖에서 전체 구간 수와 확인이 필요한 행 수를 확인합니다. 오류 구간만 보기를 누르면 영역을 열고 현재 수정할 행을 표시하며, 전체 구간 보기로 모든 행을 다시 표시합니다. 영역은 사용자 클릭으로만 펼칩니다.

오류를 수정할 때 첫 글자가 유효해져도 행을 숨기지 않아 계속 입력할 수 있습니다. 원래 구간 번호와 저장 값·전체 편집안 입력은 그대로 유지합니다. 오류가 모두 해결되거나 새 구간 추가·설정 복구·시퀀스 변경 시 전체 표시로 돌아갑니다. 카메라 충돌은 현재 확인된 행을 안내하고 수정 뒤 다시 검사합니다.

오류 보기 버튼은 작업·복구 중 잠그며 즉시 업데이트 시작 동작을 유지합니다. 전체 회귀·독립 리뷰·패키지 실행·공개 업데이트 서명/다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치는 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
