# Contentrium CUT

최소 샷 길이·짧은 발화·동시 발화에 빈 값, 음수 또는 유효하지 않은 숫자를 입력하면 해당 입력 옆에서 안내하고 편집안 생성·적용을 막습니다. 0초와 소수는 계속 지원합니다. 입력하는 즉시 이전 편집안과 컷 목록·타임라인 표시를 지우며 완료한 화자 분석은 유지합니다. 같은 오류 문구를 매 주기 다시 쓰지 않고, 두 입력칸의 폭을 유지한 채 안내합니다.

설정 저장·복구에서 원래 컷 길이 입력을 보존하고 이전 숫자 설정도 지원합니다. 편집안 요청 전과 응답 후, 적용 요청 전과 Premiere 편집 진입 직전에 다시 검사합니다. 분석·싱크·설정 저장은 컷 길이 오류만으로 차단하지 않으며 업데이트 클릭 즉시 작업 중단과 업데이트 시작을 유지합니다.

실제 패널 핸들러·전체 회귀·독립 소스 검수·패키지 실행·공개 업데이트 서명과 다운로드 해시를 검증합니다. 컴퓨터유즈·PC 재설치는 수행하지 않았습니다. 실제 Premiere/UXP 화면·편집·기존 설치 전환·Community-1 품질은 미검증입니다.
