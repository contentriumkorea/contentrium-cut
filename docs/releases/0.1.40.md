# Contentrium CUT

상태 새로고침과 재연결의 오래된 응답이 최신 편집 상태·업데이트·중단 안내를 덮지 않도록 개선했습니다.

- 가장 최근 요청과 현재 연결·작업에 속한 상태만 반영합니다. 재연결 전 응답과 오류는 새 연결을 초기화하거나 편집을 다시 허용하지 못합니다.
- 잘못된 상태와 같은 구성의 감소한 작업 번호는 부분 반영하지 않습니다. 기존 상태와 편집안을 보존하고 편집을 잠근 뒤, 새로고침으로 복구할 수 있습니다. 현재 연결 오류는 내부 정보 없이 재조회 안내를 표시합니다.
- 종료 확인은 반영한 상태와 실제 미리보기·편집 작업 종료를 확인해 전송합니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작을 유지하며 실제 작업 종료와 Premiere 정상 종료 뒤 파일을 교체합니다.
- Node473개·Python496개 회귀와 독립 검수540개·패널364개, 패키지 실행 및 공개 업데이트 발견·서명·실제 다운로드 해시를 확인합니다.

초기 연결과 heartbeat 전체 수명은 후속 검증 대상입니다. 실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 실제 품질은 미검증이며 사용자 설치를 변경하지 않았습니다. 최상단 영상 개별 컷·원본·오디오·별도 자막 트랙 보존 및 로고·추가 그래픽 비관여를 유지합니다. 이미 호출된 Adobe API의 취소나 rollback을 보장하지 않습니다.
