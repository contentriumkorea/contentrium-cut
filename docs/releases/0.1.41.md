# Contentrium CUT

heartbeat 재연결과 오래된 응답 처리로 인한 편집 연결 끊김·안내 덮기를 개선했습니다.

- 현재 연결·요청·작업에 속한 응답과 오류만 처리합니다. 이전 연결의 늦은 인증 오류가 새 연결을 초기화하지 못합니다. 폐기된 응답 뒤에는 시퀀스 조회·소스 선택·입력 생성을 계속하지 않습니다.
- 잘못된 상태 형식·감소한 작업 번호는 반영하지 않고 기존 상태와 편집안을 보존한 채 편집을 잠급니다. 현재 오류는 내부 정보를 제외한 재조회 안내를 제공하며, 새 안내는 보존합니다.
- 미리보기 정지가 응답 대기 중 완료되면 해당 응답을 폐기하고 다음 실제 유휴 상태를 확인해 종료 확인을 보냅니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작을 유지하며 실제 작업 종료와 Premiere 정상 종료 뒤 파일을 교체합니다.
- Node484개·Python496개·독립 검수221개·패널375개, 패키지 실행과 공개 업데이트 발견·서명·실제 다운로드 해시를 확인합니다.

초기 연결 전체 수명과 소스 선택 조회 이후 수명은 후속 검증 대상입니다. 실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 실제 품질은 미검증이며 사용자 설치를 변경하지 않았습니다. 최상단 영상 개별 컷·원본·오디오·별도 자막 트랙 보존, 로고·추가 그래픽 비관여를 유지합니다. 이미 호출된 Adobe API 취소·rollback을 보장하지 않습니다.
