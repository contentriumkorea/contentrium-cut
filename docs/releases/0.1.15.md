# Contentrium CUT

업데이트를 누른 직후 수동 고정 구간의 추가·삭제를 차단합니다. 분석·적용·원본 검증·중단 작업 복구·연결 없음 또는 지원하지 않는 호스트에서도 버튼과 실행 직전 검사가 같은 잠금 조건을 사용합니다. 거절된 호출은 구간 원문·저장·오류 보기 상태를 변경하지 않습니다.

설정 복구 중 새로 만들어진 구간의 삭제 버튼과 입력도 처음부터 작업 상태를 반영합니다. 이미 삭제되거나 복구로 교체된 행의 이전 삭제 콜백이 다른 구간을 삭제하지 않도록 수정했습니다. 정상 추가·삭제, 전체 입력 저장, 오류 탐색과 분석 보존은 유지합니다.

업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작과 작업 종료/정상 Premiere 종료 뒤 파일 교체 경계를 유지합니다. 전체 회귀·독립 리뷰·패키지 실행·공개 업데이트 서명/다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치는 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
