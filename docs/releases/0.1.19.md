# Contentrium CUT

편집 복구 및 Premiere 호환 확인 대기 중 카메라 역할·보이는 화자, 마이크 선택·화자 ID·오디오 스트림/채널, 연결 카메라와 시작·예비 카메라 설정을 잠급니다. 화면 비활성화와 실제 입력 처리에 같은 작업 잠금을 적용해 기존 분석·편집안과 저장 설정이 변경되지 않도록 했습니다.

잠금 해제 후에는 같은 트랙 행과 입력 값을 그대로 다시 편집할 수 있습니다. 정상 마이크 변경은 분석을, 카메라 설정 변경은 편집안을 즉시 무효화하는 기존 흐름을 유지합니다. 설정 복구와 새 시퀀스 연결 등 내부 로딩은 기존대로 작동합니다.

업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작을 유지하며 실제 작업 종료 및 정상 Premiere 종료 뒤 파일을 교체합니다. 전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명과 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치는 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
