# Contentrium CUT

모델 설치 상태 조회의 늦은 응답이 업데이트·중단 안내를 덮지 않도록 개선했습니다.

- 진행 중·조회 오류·잘못된 응답은 실제 작업 종료로 취급하지 않습니다. 종료 상태와 소유 프로세스 종료를 함께 확인한 뒤 설치 잠금을 해제합니다.
- 엔진 재시작으로 중단된 설치도 종료 확인 후 다시 시도할 수 있습니다. 현재 인증 오류는 연결을 복구하며 접근 토큰이나 제공자 오류 내용을 안내에 노출하지 않습니다. 새 작업과 새 안내는 보존합니다.
- 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작을 유지합니다. 실제 작업 종료와 Premiere 정상 종료 후 파일을 교체합니다. Node431개·Python494개, 독립 상태 전환28개·패널322개를 통과했습니다. 패키지 실행·공개 서명·실제 다운로드 해시를 확인합니다.

싱크·샘플 작업의 상태 조회와 전체 refresh는 별도 개선 대상입니다. 실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 실제 품질은 미검증이며 사용자 설치를 변경하지 않았습니다.
