# Contentrium CUT

수동 고정 구간의 시작·종료 프레임과 카메라를 입력 위치에서 확인합니다. 빈 값·소수·편집 범위 밖·역전·사용 불가 카메라·서로 다른 카메라의 겹침을 안내하고 편집안 생성·적용을 막습니다. 같은 카메라의 겹침과 인접한 경계는 계속 지원합니다.

잘못 입력한 수동 구간도 저장·복구에서 원문과 행을 보존합니다. 보호 트랙으로 바뀐 카메라는 다른 카메라로 자동 연결하지 않고 다시 선택하도록 안내합니다. 입력·삭제는 이전 컷 표시와 설정 자동 저장에 반영하며 완료한 분석·교정은 유지합니다. 실제 영상 공백 검사는 엔진이 담당하고 거절 시 한국어 수정 안내를 표시합니다.

업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작과 기존 복구 기록 보존은 유지합니다. 패널 핸들러·전체 회귀·독립 소스 검수·패키지 실행·공개 업데이트 서명/다운로드 해시를 검증합니다. 컴퓨터유즈·PC 재설치는 하지 않았습니다. 실제 Premiere/UXP 화면·편집·설치 전환·Community-1 품질은 미검증입니다.
