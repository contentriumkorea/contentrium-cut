# Contentrium CUT

미리보기 종료를 기다리는 동안 업데이트·중단 또는 연결 변경이 발생하면 이전 편집 요청을 폐기합니다. 오래된 응답이 새 미리보기 상태나 업데이트 안내를 덮지 않으며, 분석·싱크·화자 샘플·타임라인 이동·설정 복원·적용 준비가 이어지지 않습니다.

현재 작업의 미리보기 종료에 실패해도 적용 준비 잠금을 해제해 다시 시도할 수 있습니다. 새 적용 준비의 잠금과 상태는 이전 작업의 정리에서 보존합니다.

업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작을 유지합니다. 파일 교체는 실제 작업 종료와 Premiere 정상 종료 이후 진행합니다. 단일 Premiere 패널, 최상단 Contentrium CUT 영상 트랙의 수정 가능한 개별 컷, 원본·오디오·별도 자막 트랙을 유지합니다.

검증은 실제 패널 소스의 CLI 모의 회귀, 독립 리뷰, 전체 회귀, 추출 패키지 실행 및 공개 서명·다운로드 해시 확인으로 수행합니다. 실제 Premiere/UXP 편집, 사용자 설치 전환, Community-1 실제 품질은 미검증입니다. 사용자 PC에 재설치하지 않아 직접 업데이트 시험이 가능합니다.
