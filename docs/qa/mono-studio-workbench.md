# Mono Studio 05 작업 화면 복원

사용자 확인: 2026-10-19, `05 Mono Studio 최소 설정형` 기준으로 수정.
기존 4단계 화면 설계의 시각·이동 방식은 이 결정으로 대체한다.

## 수용 조건과 설계

- Premiere UXP 패널을 유지한다. 소스, 싱크, 화자 연결, 기본 편집 설정을 하나의 작업 화면에서 확인한다. 단계 탭과 이전/다음 단계 이동을 제거한다.
- 기준 이미지의 검정·차콜·흰색, 얇은 구분선, 4px 모서리, 흰색 주 버튼을 사용한다. 우측 컴포넌트 견본은 제품에 넣지 않는다.
- 소스 선택과 자동 싱크를 위쪽에, 화자 연결과 최소 컷 길이·짧은 반응 유지 설정을 아래쪽에 배치한다. 트랙 역할, 채널, 분석 민감도, 범위, 교정, 수동 구간 등은 고급 설정으로 접는다. 기존 제어와 검증을 삭제하지 않는다.
- 하단 주 동작은 준비 상태에 따라 화자 분석 → 편집안 만들기 → 검토 후 시퀀스 만들기로 바뀐다. 분석 결과·정책 변경 시 유효한 이전 단계로 돌아간다. 적용은 별도 명시적 클릭이 필요하다.
- 재분석, 편집안 다시 만들기, 설정 열기/닫기가 가능하며 입력값과 고급 설정의 펼침 상태를 보존한다.
- 원본·오디오·별도 자막·그래픽 보존, 최상단 개별 컷, 업데이트·중단·복구·오래된 편집안 차단 처리는 유지한다.

## 검증 범위

실제 패널 핸들러의 CLI 회귀 시험과 구조·상태 시험을 수행한다. 컴퓨터유즈·브라우저 자동화·Premiere 실행·재설치·배포는 이번 작업에서 수행하지 않는다. 실제 UXP 렌더링·Premiere 편집·Community-1 품질은 별도 실환경 확인이 필요하다.

## 구현 및 검수 기록

- 단계 이동을 제거하고 소스·싱크·화자·편집 설정을 같은 스크롤 영역에 배치했다. 프로젝트 클립을 읽으면 입력 시퀀스 준비 항목이 펼쳐지며, 현재 시퀀스로 돌아와도 기본 화면은 유지된다.
- 화자 이름 수정과 트랙·채널·분석 세부 설정은 고급 설정으로 옮겼다. 화자 카메라, 전체샷/예비 화면, 최소 컷 길이 슬라이더/숫자 입력, 짧은 반응 유지 스위치는 기본 화면에 둔다. 스위치는 표준 `aria-checked` 상태를 사용한다.
- 기존 분석·계획·적용 핸들러를 재사용한다. 계획이 바뀌면 적용 버튼을 숨기고 다시 계획하도록 안내한다. 설정을 열고 돌아와도 입력과 고급 설정의 펼침 상태를 보존한다.
- 독립 읽기 전용 리뷰에서 ‘계획 생성 후 검토 영역이 화면 밖에 남음’ 1건을 지적했다. 실패 시험(`0 !== 1`)을 먼저 확인한 뒤 검토 영역 스크롤/제목 포커스와 하단 검토 바로가기를 추가했다. 재검수에서 남은 주요 지적은 없었다.
- 전체 회귀에서 구형 화면 구조를 가정한 화자 선택 시험 도우미를 발견했다. 실제 선택 상자의 접근성 이름을 기준으로 조회하도록 고쳤으며, 분석 복원·화자 범위·오래된 편집안 차단 관련 12개 집중 시험이 통과했다.
- 다음 전체 회귀는 789개 중 787개 통과/2개 실패였다. 소유권 경합 시험의 임시 계획 객체에 통계 배열이 없어 새 검토 건수 표시가 실패한 것이 원인이었다. 표시만 배열 유무를 확인해 `—`로 처리하도록 고쳤으며, 해당 소유권 시험을 포함한 7개 집중 시험이 통과했다. 초기 편집 중 비고정 입력으로 실행한 결과는 완료 근거에서 제외한다.
- Python 정책 시험 첫 실행은 모듈 검색 경로 누락으로 53개 모두 import 단계에서 실패했다. 제품 변경 없이 `companion` 경로를 지정한 뒤 53개 모두 통과했다. 화면 구조 시험 3개, JS 구문 검사, 상수 ID 참조 94개 검사도 통과했다.
- 로컬 UXP 검수 패키지 16파일의 압축 CRC·원본 바이트·비공개 설정 제외 검사가 통과했다. 압축에서 추출한 패널로 새 흐름·업데이트 즉시 시작·적용 입력 재검증 관련 10개 핸들러 시험이 통과했다. 이는 Adobe 등록/설치/실제 패널 실행을 검증한 결과가 아니다.
- 로컬 증거는 공개 대상에서 제외된 `.superpowers/mono-studio-20261019/`에 보존했다. 기존 공개 파일과 사용자 설치본을 교체하지 않았으며 제품 버전은 0.1.109를 유지한다. 새 공개 배포는 수행하지 않았다.

## 최종 결과

- 고정한 최종 입력으로 `npm test`: 789개 통과, 실패/제외 0개.
- Python 정책 53개와 화면 구조 3개 통과. 최종 패키지에서 추출한 실제 JS/HTML을 대상으로 한 핵심 핸들러 시험 10개 통과.
- 독립 리뷰의 중요 지적 1개 수정 및 재검수 완료, 남은 중요 지적 없음. 최종 스위치·통계 표시 보완도 추가 읽기 전용 검수를 마쳤다.
- JS 구문·ID 참조·Git 공백 검사, 7개 소스/시험 파일의 실행 전후 SHA-256 일치 확인 완료. 로컬 UXP 검수 패키지 SHA-256: `02c4b64043d3a66e01f6199109d5b768ee52811ded12751b8ab3999227f9c082`.
- 완료 범위는 로컬 소스 수정과 CLI 검증이다. 실제 Premiere에서 화면·키보드·스크린리더·편집 결과 및 Community-1 품질을 확인하지 않았다. 설치/공개 배포를 완료한 상태로 간주하지 않는다.
- 이어갈 단계: 사용자 직접 실환경 확인 또는 별도 배포 요청에 따른 새 버전 패키징. 반복 자동화는 재개하지 않는다.
