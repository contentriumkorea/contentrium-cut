# Contentrium CUT

마이크 누설음 보정의 단독 발화 구간을 입력하는 즉시 검사합니다. 빈 값·소수·역순·마이크 클립 범위 밖 구간은 행별 안내와 함께 분석 시작을 차단합니다. 시작과 종료를 모두 0으로 두면 기존처럼 보정을 사용하지 않습니다. 프레임 경계는 정확한 Premiere tick으로 확인하며, 분석할 편집 범위 밖이지만 해당 마이크 클립 안인 예시는 계속 사용할 수 있습니다.

선택한 개별 마이크의 교정만 분석에 사용합니다. 혼합 녹음 또는 선택하지 않은 마이크의 교정은 용도를 표시하고 입력을 비활성화하며 원문을 보존합니다. 활성 구간을 입력 중 수정하면 기존 분석과 편집안을 즉시 무효화합니다. 이전 저장 분석의 정확한 입력 참조도 호환 복구하고 작업·복구·업데이트 잠금과 비동기 분석 직전 검사를 유지합니다. 서버 직접 요청도 구간·화자·선택 마이크를 디코드 전에 확인합니다.

업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작과 작업 종료/정상 Premiere 종료 뒤 파일 교체 경계를 유지합니다. 전체 회귀·독립 리뷰·패키지 실행·공개 업데이트 서명/실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치는 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
