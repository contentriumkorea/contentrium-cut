# Contentrium CUT

편집 복구·호환 확인·업데이트 및 작업 대기 중 수동 고정 구간의 시작·종료·카메라 입력을 잠급니다. 화면과 직접 입력 콜백에 동일한 작업 잠금 조건을 적용하여 현재 화자 분석·편집안·검토·원문·자동 저장 상태를 보존합니다. 내부 설정 복구로 생성되는 행에도 잠금을 즉시 적용합니다.

잠금 해제 후 같은 행과 입력값으로 편집을 재개합니다. 범위·겹침·고정 카메라 오류 검사를 유지하며, 입력 변경은 기존 화자 분석을 보존하고 편집안만 다시 만들도록 합니다. 저장 raw 복구·새 시퀀스 초기화·추가/삭제/오류 행 필터의 기존 동작을 유지합니다.

자동 저장이나 타임라인 조회가 대기 중이어도 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차를 시작합니다. 실제 작업 종료와 정상 Premiere 종료 뒤 파일을 교체합니다. 전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명 및 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치를 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
