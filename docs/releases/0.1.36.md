- 설치 준비 중에도 실제 중단 버튼을 사용할 수 있습니다. 새 연결·입력·다른 검증 작업 이후에는 이전 응답과 추가 설치 요청을 차단합니다.

- 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작을 유지합니다. Node 424개·Python 493개, 독립 검수 480개·패널 315개를 통과했습니다. 패키지 실행·공개 발견·서명·실제 다운로드 해시를 확인합니다.
