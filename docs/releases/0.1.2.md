# Contentrium CUT

- 롱폼 컷 검토에 카메라 필터와 선택 이유 검색을 추가했습니다. 필터링해도 Premiere에 적용할 전체 편집안은 유지됩니다.
- 목록을 50컷씩 나누고 이전·다음 이동과 표시 개수를 제공합니다. 뒤 페이지의 컷도 원래 프레임 위치로 이동합니다.
- 모노 스튜디오 패널의 헤더·외곽 여백·목록 간격을 줄이고 검색·페이지 컨트롤의 줄바꿈을 보완했습니다.
- 후속 버전이 공개되어도 기존 0.1.0의 소스 보조 복구가 정확한 v0.1.1을 확인하도록 보완했습니다. 일반 패널 업데이트는 최신 공개 버전을 확인합니다.

단일 Premiere 패널, 최상단의 수정 가능한 개별 컷, 원본과 별도 자막 트랙 보존 계약을 유지합니다. 업데이트를 누르면 즉시 CUT 새 작업을 차단하고 중단 요청과 업데이트 절차를 시작하며, 파일 교체는 Premiere 정상 종료 뒤 진행합니다.

사용자 PC에는 재설치하지 않았습니다. 설치된 새 UXP 화면·Premiere 편집 결과·기존 설치의 실제 전환과 Community-1 실음성 품질은 아직 미검증입니다. [반복 개선 검수 기록](https://github.com/contentriumkorea/contentrium-cut/blob/main/docs/qa/continuous-improvement.md)에서 실행한 검증 범위를 확인할 수 있습니다.
