# Contentrium CUT

중단 요청을 더 빠르게 제출하고, 늦은 응답이 업데이트 안내와 연결을 덮는 문제를 개선했습니다.

- 미리보기 종료를 기다리지 않고 파일 확인·분석 중단을 함께 시작합니다. 일부 요청이 실패해도 나머지 중단 요청을 보내고 응답을 확인합니다.
- 중단 확인 중에는 진행 문구와 잠금을 표시하고 중복 요청·추가 편집·자동 설정 저장을 막습니다. 새 상태 조회가 미완료 중단을 편집 재개로 표시하지 않습니다. 업데이트 클릭은 기존 즉시 경로를 유지합니다.
- 새 업데이트·연결·작업·안내 뒤 이전 중단 응답을 폐기합니다. 현재 인증·패널 충돌은 안전하게 처리하며 실제 Adobe 트랜잭션·재생 종료를 대신 선언하지 않습니다.

Node558개·Python496개·독립622개 시나리오·패널435개를 통과했습니다. 독립 리뷰·패키지 실행·공개 발견·서명·실제 다운로드 해시 검증을 포함한 배포 절차를 적용합니다.

실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 품질은 미검증이며 사용자 설치를 변경하지 않았습니다. 파일 교체는 실제 작업 종료와 Premiere 정상 종료 뒤 진행합니다. 최상단 개별 영상 컷·원본·오디오·별도 자막 트랙을 보존하고 로고·추가 그래픽에 관여하지 않습니다. 이미 발행한 API·저장소·물리 전송의 취소나 rollback을 보장하지 않습니다.
