# Contentrium CUT

분석 자원 설정을 조회·저장하는 동안 업데이트·중단하거나 입력이 바뀌어도, 이전 응답이 새 설정과 안내를 덮지 않도록 개선했습니다.

- 설정 저장의 POST/후속 GET과 설정 창의 초기 조회를 요청별로 보호합니다. 중단 후 추가 조회를 막고, 이전 성공·오류와 입력/창/검증 상태가 돌아오는 경우도 구분합니다.
- 편집 복구 중 인증된 읽기 전용 설정 조회를 유지합니다. 저장하지 않은 입력은 창을 다시 열어도 보존하고, 응답 해석 오류가 입력 일부를 먼저 바꾸지 않습니다.
- 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작을 유지합니다. Node 404개·Python 493개, 독립 검수 718개·패널 295개 통과. 패키지 실행 및 공개 발견·서명·실제 다운로드 해시 증거를 배포 후 확인합니다.

캐시 정리·해제 POST의 늦은 응답 처리는 다음 회차 개선 대상입니다. 기존 캐시 drain/release 동작은 회귀 검증했습니다. 이미 제출된 서버 설정 변경의 취소나 되돌림을 주장하지 않습니다. 실제 Premiere/UXP 편집·기존 0.1.0 설치 전환·Community-1 실제 품질은 미검증이며 사용자 설치는 변경하지 않았습니다.
