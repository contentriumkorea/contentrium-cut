# Contentrium CUT

편집 복구 또는 호환 확인 대기 중 분석 범위 시작·종료와 최소 컷 길이·짧은 발화·겹침 컷 옵션을 잠급니다. 화면 비활성화와 입력 콜백에 같은 작업 잠금 조건을 적용하여 현재 분석·편집안·화자 연결 및 자동 저장 상태를 보존합니다. 최초 연결 대기에서도 입력을 즉시 잠급니다.

잠금을 해제하면 기존 입력값을 그대로 유지하고 유효성 검사와 편집을 재개합니다. 범위 변경은 재분석을, 컷 옵션 변경은 새 편집안을 요구하는 기존 동작을 유지합니다. 내부 설정 복구와 새로운 시퀀스 읽기는 대기 중에도 정상 반영합니다.

자동 저장이나 타임라인 조회가 대기 중이어도 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차를 시작합니다. 실제 작업 종료와 정상 Premiere 종료 뒤 파일을 교체합니다. 전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명 및 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치를 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
