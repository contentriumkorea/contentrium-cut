# Contentrium CUT

- 마이크 행에서 채널·오디오 스트림·화자 ID의 입력 오류를 바로 표시합니다. 선택한 마이크의 기본 형식이 잘못됐거나 선택이 없으면 분석 요청 전에 수정하도록 안내합니다.
- 입력 중에도 오류와 분석 버튼 상태를 갱신하고 이전 분석·편집안을 무효화합니다. 저장된 잘못된 값을 자동으로 바꾸지 않고 해당 행에서 고치도록 안내합니다.
- 미선택 마이크는 검사에서 제외하고, 혼합 녹음에서는 빈 화자 ID를 허용합니다. 유효한 값의 0 기준 요청 변환과 실제 미디어의 채널·스트림 존재 여부를 확인하는 엔진 검증을 유지합니다.

채널/스트림의 기본 형식 검사는 기존 UI 표시 범위인 1–64 / 1–256의 정수에 적용합니다. 중복 화자 ID는 동일 화자의 여러 녹음일 수 있으므로 허용하고, 정확한 시간 범위·할당 충돌은 엔진이 검사합니다.

단일 Premiere 패널, 수정 가능한 최상단 개별 컷, 원본·오디오·별도 자막 트랙을 유지합니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작을 유지하며 실제 작업 종료와 Premiere 정상 종료 뒤 파일을 교체합니다.

사용자 PC에 재설치하거나 컴퓨터유즈를 사용하지 않았습니다. 실제 새 UXP 화면·Premiere 편집·기존 설치 전환 및 Community-1 실음성 품질은 아직 미검증입니다. 이전 취소 시험의 간헐 실패 원인은 미확정으로 추적합니다. [반복 개선 기록](https://github.com/contentriumkorea/contentrium-cut/blob/main/docs/qa/continuous-improvement.md)에서 검증 범위를 확인할 수 있습니다.
