# Contentrium CUT

화자 분석 도중 취소·업데이트 후 도착한 완료 결과와 오류가 중단 안내·분석·화자 연결·저장 상태를 덮지 않습니다. 작업 조회, 호스트 타임라인 조회, 분석 등록의 각 응답 뒤 현재 작업·연결·분석 범위와 작업 허용 상태를 다시 확인하며 새로운 작업과 연결을 보존합니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차를 시작하고 실제 작업 종료 및 정상 Premiere 종료 뒤 파일을 교체합니다.

정상 완료에서도 분석 등록 이후 타임라인을 다시 확인한 뒤 결과와 저장할 분석 작업 참조를 반영합니다. 대기 중 실제 타임라인이 바뀌면 결과를 수락하지 않고 시퀀스 재조회 안내를 표시합니다. 정상 조회 오류는 안내에 표시하며 일시적인 파일 검증 처리량 제한은 현재 작업을 보존해 재시도합니다. 분리/혼합 녹음의 정상 분석·재분석·편집안 생성·설정 저장, 입력 소스 확인·싱크·음성 샘플 흐름을 유지합니다.

전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명 및 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치를 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
