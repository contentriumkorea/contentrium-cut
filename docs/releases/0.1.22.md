# Contentrium CUT

편집 복구·호환 확인·업데이트 및 작업 대기 중 싱크 설정 전체를 잠급니다. 싱크 방법·기준 소스·참여 선택·오디오 스트림/채널과 수동 오프셋·타임코드 확인 입력의 표시 및 콜백에 같은 잠금 조건을 적용해 완료 싱크 결과·현재 분석/편집안·자동 저장 상태를 보존합니다.

잠금 해제 후 기존 행과 입력값을 그대로 유지하며 유효성 검사와 편집을 재개합니다. 싱크 설정 변경 시 결과를 무효화하는 기존 동작과 다음 분석 옵션을 유지합니다. 내부 저장 설정 복구·방법별 필드 표시·새 시퀀스 읽기는 작업 대기 중에도 정상 반영합니다.

자동 저장이나 타임라인 조회가 대기 중이어도 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차를 시작합니다. 실제 작업 종료와 정상 Premiere 종료 뒤 파일을 교체합니다. 전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명 및 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치를 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
