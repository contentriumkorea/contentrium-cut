# Contentrium CUT

초기 연결 확인 중 중단·업데이트를 눌렀을 때, 이전 응답이 편집을 다시 열거나 새 안내를 덮는 문제를 개선했습니다.

- 연결과 중단 작업 기록을 확인하는 동안 편집을 잠그고 중단 버튼을 제공합니다. 늦은 연결·시퀀스·업데이트 확인 응답은 현재 작업에 속할 때만 처리합니다. 중단된 미완료 연결은 새로고침으로 다시 확인할 수 있습니다.
- 연결 확인이 끝나면 업데이트 확인의 네트워크 대기 중에도 편집할 수 있습니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작은 유지하며, 파일 교체는 실제 작업 종료와 Premiere 정상 종료 뒤 진행합니다.
- 이전 편집 기록의 형식을 검증하고 손상된 기록은 복구 잠금을 유지합니다. 새 안내를 보존하면서도 잘못된 설치 정보는 복구 전 자동으로 재시도하지 않습니다.

Node513개·Python496개·독립175개 시나리오·패널404개를 통과했습니다. 패키지 실행과 공개 업데이트 발견·서명·실제 다운로드 해시를 확인합니다.

실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 품질은 미검증이며 사용자 설치를 변경하지 않았습니다. 최상단 개별 영상 컷·원본·오디오·별도 자막 트랙을 보존하며 로고·추가 그래픽에 관여하지 않습니다. 이미 발행한 Adobe/API 호출 취소·rollback이나 connection 전송 전체 수명까지 보장하지 않습니다.
