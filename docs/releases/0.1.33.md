# Contentrium CUT

설정 저장이 늦게 끝나도 업데이트·중단 안내와 새 시퀀스의 설정을 보존합니다. 수동 저장과 자동 저장을 순서대로 처리하고, 가장 최근 요청만 대기열에서 제출하여 오래된 설정이 나중에 덮어쓰지 않도록 개선했습니다.

- 업데이트 클릭 즉시 작업을 차단하고 업데이트 요청을 시작합니다. 아직 제출하지 않은 저장은 건너뛰고, 이미 제출된 저장의 완료·오류가 새 안내를 바꾸지 않습니다.
- 교체된 자동 저장 타이머와 새 검증·분석 진행 안내의 소유권을 확인합니다. 정상 분석 중 자동 저장과 현재 저장 오류 안내, raw 입력·분석 reference 복원은 유지합니다.
- Node 392개·Python 493개, 독립 저장 검수 512개·패널 283개를 통과했습니다. 패키지 실행과 공개 업데이트 발견·서명·실제 다운로드 해시는 배포 후 증거 파일에서 확인합니다.

실제 Premiere/UXP 편집·기존 0.1.0 설치 전환·Community-1 실제 품질은 미검증입니다. 사용자 설치를 변경하지 않았습니다. 이미 제출된 저장소 쓰기의 취소나 되돌림을 주장하지 않습니다. 분석 자원 설정 저장 응답은 다음 회차 개선 대상으로 기록했습니다.
