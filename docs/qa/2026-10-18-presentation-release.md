# Contentrium CUT 배포 소개 정비 — 2026-10-18

## 범위와 수용 조건

- 사용자 요청으로 Contentrium Dev Skill의 플러그인 소개·설치 안내·승인된 배포·릴리스 관리 기준을 적용한다. Premiere 플러그인과 로컬 분석 엔진 구조를 유지한다.
- 프로젝트 전용 커버, 짧은 소개, 최신 다운로드, 실제 기능, 명확히 표시한 사용 예시, 짧은 설치·사용 방법, 콘텐츠리움 홈페이지 버튼 순서로 첫 화면을 정리한다.
- 기존 사용자·개발·검증 안내는 별도 문서로 보존한다. 소개와 릴리스 본문은 사용자 기능·변경 사항 중심으로 정리한다.
- 제품 코드·설정·버전·설치본·서명된 배포 파일을 변경하지 않는다. 현재 v0.1.109의 소개와 릴리스 설명을 갱신한다. 새 버전이나 중복 자산을 만들지 않는다.

## 확인한 내용

- README와 새 문서의 상대 링크, 세 SVG의 구조·접근성 설명·외부 자원 부재, 개인 경로·인증정보 패턴을 검사했다. 설치·업데이트 진입 파일명과 주소를 유지했다.
- 커버와 기능 흐름도를 렌더링하고 데스크톱·360px 폭에서 시각 검수했다. GitHub Markdown API의 렌더링에서 커버 위치·이미지 대체 텍스트·접기 영역·홈페이지 링크를 확인했다. 흐름도는 실제 제품 화면이 아님을 이미지와 본문에 표시한다.
- 독립 검수에서 문서 링크·배포 기준·기능 설명·호환성에 배포 차단 지적이 없었다. 공개 후 파일과 다운로드·서명·자산 보존 확인 결과는 별도 로컬 QA 기록으로 보존한다.

## 이전 릴리스 공개 유지 사유

현재 공개 릴리스 목록은 110개이며 첨부 파일은 558개다. 사용자 다운로드는 최신 정식 버전으로 연결한다. 다만 기존 설치기·업데이터·복구 도구는 버전별 자산 주소와 릴리스 ID를 참조한다. 진행 중인 업데이트의 재확인과 고정 v0.1.1 전환도 원래 식별 정보에 의존한다.

이전 버전을 초안으로 숨기면 이미 배포한 연결을 보존할 수 없거나 실제 이용자의 진행 상태를 확인할 수 없다. 따라서 스킬의 호환성 예외에 따라 이전 릴리스를 공개로 유지한다. 기존 파일·태그·서명·릴리스 ID·고정 주소·`target_commitish`는 변경하지 않는다. 릴리스 본문 갱신은 서명된 배포 정보의 변경과 구분한다.

## 유지하는 한계

실제 다른 PC 설치 성공, Premiere 첫 연결·편집, Community-1 실제 화자 구분 품질은 미검증이다. 사용자 PC 재설치·활성화, Premiere 실행·조작·종료, 브라우저 자동화와 반복 자동화 재개는 수행하지 않는다. 이전 이력 정리에서 확인된 옛 SHA 직접 조회의 서버 보관 문제는 사용자가 추가 요청 없이 마무리한 범위로 유지한다.
