# Contentrium CUT

프로젝트 소스를 제외했다가 다시 포함해도 이전 출력 오디오 선택을 유지합니다. 제외 중에는 체크를 비활성화하고 실제 입력 시퀀스 생성 요청의 오디오 출력은 차단합니다. 다시 포함하면 확인된 오디오 소스의 기존 선택으로 편집을 재개합니다.

행별 제외·미디어 확인 중·오디오 스트림 없음 안내를 표시합니다. 확인 전과 작업/복구/호환/업데이트 대기에는 역할과 출력 체크를 잠그며, 오디오가 없는 소스는 출력할 수 없습니다. 새 소스 선택은 기존 기본값으로 시작하고 오래된 행의 이벤트는 무시합니다. 연결된 타임라인이 없어도 프로젝트 소스에서 입력 시퀀스를 만드는 흐름과 현재 분석·편집안·싱크·설정을 보존합니다.

미디어 확인이 대기 중이어도 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차를 시작합니다. 실제 작업 종료와 정상 Premiere 종료 뒤 파일을 교체합니다. 전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명 및 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치를 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
