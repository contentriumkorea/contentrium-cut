- 소스 조회·등록·미디어 확인 접수를 모두 검증한 뒤 새 목록을 한 번에 반영합니다. 준비나 실패 중 기존 소스 역할과 오디오 선택을 보존하며, 다시 읽을 수 있는 안내를 제공합니다.

- 정상적인 주기적 상태 조회가 긴 소스 조회를 방해하지 않으며, Premiere 원본 항목 참조를 그대로 보존해 입력 시퀀스 생성에 전달합니다.
