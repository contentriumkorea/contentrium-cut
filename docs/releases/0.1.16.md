# Contentrium CUT

개별 마이크의 발화 민감도와 혼합 녹음의 예상 화자 수를 입력하는 즉시 확인합니다. 빈 값·범위를 벗어난 값·소수 화자 수는 필드 아래에 수정 안내를 표시하고 분석 시작을 차단합니다. 분석 시작 중에도 입력과 업데이트 상태를 다시 확인합니다.

현재 녹음 방식에서 사용하지 않는 설정은 용도 안내와 함께 비활성화합니다. 해당 설정의 원문은 보존하며 분석 결과에는 영향을 주지 않습니다. 저장한 빈 값과 0을 임의로 기본값으로 바꾸지 않으며, 이전 버전의 유효한 저장 분석 참조도 복구합니다. 활성 설정을 수정하면 기존 분석과 편집안을 바로 무효화합니다. 서버 직접 요청에도 같은 범위·타입 검사를 적용합니다.

업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작과 작업 종료/정상 Premiere 종료 뒤 파일 교체 경계를 유지합니다. 전체 회귀·독립 리뷰·패키지 실행·공개 업데이트 서명/다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치는 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
