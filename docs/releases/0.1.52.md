# Contentrium CUT

캐시 예산 입력의 오류를 즉시 표시하고, 잘못된 예산의 자원 설정 저장을 차단합니다.

- 0·음수·저장 가능한 바이트 범위를 벗어난 값을 입력하면 해당 필드에 오류를 표시합니다.
- 값을 고치면 오류와 저장 잠금을 복원합니다. 빈 값은 기존 예산을 유지하며, 양수 소수의 기존 바이트 환산 기준을 유지합니다.
- 입력 중 기존 분석 안내와 편집안을 유지하고, 기존 작업 잠금·저장 진행 표시·클릭 즉시 업데이트 경로를 보존합니다.
