# Contentrium CUT

수동 업데이트 확인 중 취소·업데이트 이후 늦은 응답이 새 안내를 덮거나 작업 상태를 바꾸는 문제를 개선했습니다.

- 확인 버튼의 중복 클릭을 막고, 연결 준비가 끝나지 않았을 때는 확인을 시작하지 않습니다. 확인 중에도 편집과 즉시 업데이트·중단은 사용할 수 있습니다.
- 확인과 후속 상태 조회가 같은 요청·연결·중단 상태에 속할 때만 반영합니다. 새 안내를 보존하면서 현재 인증·패널 충돌은 안전하게 처리하고, 일반 실패에는 재시도 안내를 표시합니다.
- 상태 조회에서 업데이트 정지를 발견하면 실제 유휴 상태를 확인해 응답합니다. 진행 중인 Adobe 작업·재생을 유휴로 간주하지 않으며, 파일 교체는 실제 작업 종료와 Premiere 정상 종료 뒤 진행합니다.

Node521개·Python496개·독립523개 시나리오·패널412개를 통과했습니다. 패키지 실행과 공개 발견·서명·실제 다운로드 해시를 검증하는 배포 절차를 적용합니다.

실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 품질은 미검증이며 사용자 설치를 변경하지 않았습니다. 최상단 개별 영상 컷·원본·오디오·별도 자막 트랙을 보존하고 로고·추가 그래픽에 관여하지 않습니다. 업데이트 복구 handler·connection 물리 전송의 취소·이미 발행한 API rollback은 후속 검증 대상입니다.
