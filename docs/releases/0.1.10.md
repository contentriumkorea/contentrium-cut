# Contentrium CUT

싱크 결과를 분석에 사용한 입력과 연결해 오래된 결과의 적용을 막습니다. 분석 중 입력이 바뀌면 완료 결과를 사용하지 않고 다시 분석하도록 안내합니다. 적용 버튼을 누를 때와 승인 응답을 받은 뒤에도 입력·결과 작업이 같은지 확인합니다.

자동·수동·타임코드 방식에서 실제 사용하는 값만 비교합니다. 일치 검사에서 자동 싱크의 미사용 수동/타임코드 값과 수동 싱크의 기준 소스 오프셋은 제외합니다. 입력 출처를 확인할 수 없는 결과도 새 분석을 요구합니다. 주기 확인에서 오래된 결과를 감지하면 기존 결과 표시를 지우고 재분석을 안내합니다. 기존 입력 이벤트의 즉시 무효화·원시 설정 보존·업데이트 클릭 즉시 작업 차단은 유지합니다.

패널 핸들러·전체 회귀·독립 소스 검수, 패키지 실행과 공개 업데이트 서명·다운로드 해시를 검증합니다. 컴퓨터유즈·PC 재설치는 수행하지 않았으며 실제 Premiere/UXP 화면·편집·기존 설치 전환·Community-1 품질은 미검증입니다.
