# Contentrium CUT

캐시 정리·잠금 해제 중 업데이트나 중단을 눌렀을 때, 이전 응답이 안내와 설정을 덮거나 추가 조회를 시작하지 않도록 개선했습니다.

- 정상 캐시 정리의 검증 요청을 구분해 잠금·재개를 유지합니다. 다른 검증 작업·연결·입력·새 요청이 시작되면 오래된 응답을 폐기합니다.
- 캐시 잠금 해제는 실제 정리 작업이 종료된 뒤에만 가능합니다. 후속 상태 조회가 새 업데이트 후보·모델 상태·복구 기록을 덮지 않습니다.
- 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작을 유지합니다. Node414개·Python493개를 통과했고, 독립 검수727개·패널305개를 통과했습니다. 패키지 실행·공개 발견·서명·실제 다운로드 해시를 검증합니다.

이미 서버에서 수행한 캐시 삭제의 취소나 되돌림을 주장하지 않습니다. 다른 모델/전체 상태 조회의 응답 소유권은 별도 개선 대상입니다. 실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 실제 품질은 미검증이며 사용자 설치를 변경하지 않았습니다.
