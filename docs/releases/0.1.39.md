# Contentrium CUT

단독 발화 샘플의 늦은 조회·재생 응답이 업데이트·중단 안내와 새 작업을 덮지 않도록 개선했습니다.

- 현재 분석과 타임라인을 확인한 샘플만 재생합니다. 잘못된 샘플 정보·종료가 확인되지 않은 작업은 재생하지 않고 재조회합니다. 분석 내용 변경이나 중단으로 조회가 막혀도 인증된 상태의 실제 종료 증거로 정리할 수 있습니다.
- 재생 준비와 정지 응답을 기다리는 동안 새 편집과 종료 확인을 보류합니다. 이미 시작된 재생 호출이 늦게 끝나면 해당 재생의 정지를 확인하며, 이전 타이머·정지 응답이 새 미리보기 상태와 안내를 해제하지 못하게 했습니다.
- 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작을 유지합니다. 파일 교체는 실제 작업 종료와 Premiere 정상 종료 뒤 진행합니다. Node460개·Python496개 회귀가 통과했습니다. 독립 검수932개·패널351개도 통과했습니다. 패키지 실행·공개 서명·실제 다운로드 해시를 확인합니다.

전체 refresh 수명과 실제 호스트 환경은 별도 검증 대상입니다. 실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 실제 품질은 미검증이며 사용자 설치를 변경하지 않았습니다. 영상 개별 컷·원본·오디오·별도 자막 트랙을 보존하고 로고나 추가 그래픽 편집에 관여하지 않습니다. 이미 호출된 Adobe API의 취소나 rollback을 보장하지 않습니다.
