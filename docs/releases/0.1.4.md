# Contentrium CUT

- 하단 실행 버튼 바로 위에 현재 단계의 필요한 조치를 표시합니다. 시퀀스 연결, 모델 준비, 화자 분석과 편집안 생성 순서를 안내합니다.
- 단계 이동과 모델·작업 상태 변화에 맞춰 안내를 갱신합니다. 연결 오류 뒤에도 기존 처리 중 안내가 남지 않도록 보완했습니다.
- 업데이트·중단 작업 복구·원본 파일 확인 등 작업을 막는 상태를 일반 단계 안내보다 먼저 표시합니다. 안내가 바뀌지 않았으면 같은 내용을 다시 쓰지 않습니다.

기존 실행 허용 조건과 편집안을 유지합니다. 안내는 실제 모델 검증·호스트 실행 검증을 대신하지 않으며, 새 작업 차단이나 복구 조건을 우회하지 않습니다. 단일 Premiere 패널, 최상단의 수정 가능한 개별 컷, 원본·오디오·별도 자막 트랙 보존 계약을 유지합니다.

업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작을 유지하고 파일 교체는 Premiere 정상 종료 뒤 진행합니다. 사용자 PC에는 재설치하지 않았습니다. 실제 새 UXP 화면·Premiere 편집·기존 설치 전환 및 Community-1 실음성 품질은 아직 미검증입니다. [반복 개선 기록](https://github.com/contentriumkorea/contentrium-cut/blob/main/docs/qa/continuous-improvement.md)에서 검증 범위를 확인할 수 있습니다.
