# Contentrium CUT

- 혼합 녹음 모델의 조회·설치 요청 또는 설치 작업이 실패하면 권한·네트워크 확인과 토큰 재입력 방법을 안내합니다. 외부 오류 상세와 로컬 경로 대신 제한된 오류 코드만 표시합니다.
- 중단 요청 중과 실제 설치 작업 종료를 구별합니다. 취소·업데이트 중단 뒤 완료 안내를 표시하지 않으며, 다시 설치하면 이전 안내를 갱신합니다.
- 모델 정보 오류를 한국어로 표시하고, 발화 모델은 Setup 복구·혼합 녹음 모델은 설정 재설치로 안내합니다. 설치 완료 뒤에도 다음 분석에서 모델 무결성을 확인한다는 점을 명시합니다.

단일 Premiere 패널, 수정 가능한 최상단 개별 컷, 원본·오디오·별도 자막 트랙을 유지합니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작을 유지하며 실제 작업 종료와 Premiere 정상 종료 뒤 파일을 교체합니다.

사용자 PC에 재설치하지 않았고 제공자 접근·토큰 취득·약관 동의는 수행하지 않았습니다. 실제 새 UXP 화면·Premiere 편집·기존 설치 전환 및 Community-1 실음성 품질은 아직 미검증입니다. 이전 취소 시험의 간헐 실패 원인은 미확정으로 추적 중입니다. [반복 개선 기록](https://github.com/contentriumkorea/contentrium-cut/blob/main/docs/qa/continuous-improvement.md)에서 검증 범위를 확인할 수 있습니다.
