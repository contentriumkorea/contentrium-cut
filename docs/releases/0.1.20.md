# Contentrium CUT

분석에서 제외한 마이크의 화자 ID·오디오 스트림·채널을 수정해도 현재 화자 분석과 편집안을 유지합니다. 입력값은 그대로 자동 저장하며, 미선택 행에 제외 상태와 다시 선택하면 적용된다는 안내를 표시합니다.

선택하지 않은 마이크의 빈 값이나 잘못된 값은 현재 분석을 차단하지 않습니다. 다시 선택하면 입력을 검사하고 분석·편집안을 무효화합니다. 선택된 마이크의 입력 변경도 기존처럼 즉시 재분석을 요구합니다. 미선택 입력만 바뀐 저장 분석은 같은 시퀀스와 유효한 분석 참조가 확인되면 새 작업 없이 복구할 수 있습니다. 화자 연결·수동 구간·싱크와 기존 모드별 기본 선택을 보존합니다.

작업·복구·업데이트 잠금을 유지하며, 자동 저장이 대기 중이어도 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차를 시작합니다. 실제 작업 종료 및 정상 Premiere 종료 뒤 파일을 교체합니다. 전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명과 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치는 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
