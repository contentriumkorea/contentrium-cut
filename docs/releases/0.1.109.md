## 바뀐 점

- 온라인 설치기와 전체 설치 창을 같은 모노 디자인으로 정리하고 깃털 아이콘을 단색 C 아이콘으로 바꿨습니다.
- 실제 다운로드 진행률·용량·속도·예상 남은 시간을 표시합니다. 수치를 측정할 수 없는 검증·등록·연결 단계는 처리 중으로 표시합니다.
- 기존 설치를 확인하는 동안 먼저 진행 화면을 표시하고, 취소를 요청하면 안전한 경계에서 중단합니다.
- 전체 설치 창의 오류가 일반 인계 안내로 가려지던 문제를 수정했습니다. 오류 코드·해결 안내·종료 코드를 표시하고 **진단 내용 복사**와 재시도를 제공합니다.
- 설치 시작 전 오류도 진단에 포함하고, 전체 설치 창으로 이어지는 시작 환경을 개선했습니다.

이번 재게시에서는 소개·설치 안내와 GitHub 첫 화면을 정리했습니다. 프로그램 버전과 기존 배포 파일은 유지합니다.

## 설치와 사용

1. 온라인 설치기를 실행하고 **다운로드 및 설치**를 누릅니다.
2. 전체 설치 창의 안내에 따라 프로젝트를 저장하고 Premiere를 정상 종료한 뒤 설치합니다.
3. Premiere의 **Window → UXP Plugins → Contentrium CUT**을 열어 첫 연결을 마칩니다. 기존 설치는 패널의 **업데이트**로 갱신합니다.

실패하면 **진단 내용 복사**의 오류 코드와 해결 안내를 확인하세요. 인계 안내만으로 실패 원인을 단정하거나 기존 자료·설정·복구 기록을 삭제하지 마세요.

배포 정보의 서명과 다운로드 파일의 무결성을 확인합니다. 배포 정보 서명은 Windows Authenticode와 별개입니다. 기존 업데이트와 고정 `v0.1.1` 전환 연결을 유지합니다.

대상은 **Windows x64 / Premiere Pro 26.5.2**입니다. 실제 다른 PC 설치 성공·Premiere 첫 연결과 편집·Community-1 실제 품질은 별도 미검증입니다.
