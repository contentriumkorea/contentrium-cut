# Contentrium CUT

미디어 확인 도중 취소·업데이트를 누른 뒤 도착한 결과와 오류를 무시합니다. 중단·업데이트 안내를 유지하며, 오래된 확인 결과로 역할·출력 오디오·생성 버튼을 다시 활성화하지 않습니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차를 시작합니다. 실제 작업 종료와 정상 Premiere 종료 뒤 파일을 교체합니다.

작업 상태 조회와 미디어 결과 조회 이후 현재 작업·선택·행·epoch 및 작업 허용 상태를 다시 확인합니다. 새로운 작업이나 선택은 이전 응답이 덮지 않습니다. 미디어 응답의 모든 행을 확인한 뒤 한 번에 반영하고, 정상 조회에서 발생한 오류는 안내에 표시합니다. 취소 뒤 소스를 다시 읽는 흐름, 정상 확인 기본값, 소스 제외·복귀 시 오디오 선택 보존, 타임라인 없이 입력 시퀀스 생성과 기존 분석·편집안·싱크·설정을 유지합니다.

전체 회귀·독립 리뷰·패키지 실행·익명 공개 서명 및 실제 다운로드 해시를 검증합니다. 컴퓨터유즈·Premiere 조작·PC 재설치를 하지 않았습니다. 실제 UXP 화면·Premiere 편집·설치 전환·Community-1 품질은 미검증입니다.
