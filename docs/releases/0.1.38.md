# Contentrium CUT

싱크 조회의 늦은 진행·오류·결과가 업데이트·중단 안내와 새 설정을 덮지 않도록 개선했습니다.

- 해당 조회의 원본 검증만 이어받고, 결과를 반영하기 전 타임라인과 싱크 설정을 다시 확인합니다. 잘못된 결과는 부분 반영하지 않습니다.
- 실제 프로세스 종료까지 작업 잠금을 유지합니다. 원본 변경이나 업데이트 중단으로 결과 조회가 막혀도, 인증된 상태에서 종료를 확인하면 안전하게 정리하고 다시 분석할 수 있습니다. 새 작업과 안내를 보존하며 인증 오류는 현재 조회에서만 연결을 복구합니다.
- 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 시작을 유지합니다. Node447개·Python495개, 독립 검수794개·패널338개를 통과했습니다. 패키지 실행·공개 서명·실제 다운로드 해시를 확인합니다.

단독 발화 샘플 조회와 전체 refresh는 별도 개선 대상입니다. 실제 Premiere/UXP 편집·기존0.1.0 설치 전환·Community-1 실제 품질은 미검증이며 사용자 설치를 변경하지 않았습니다. 영상 개별 컷·원본·오디오·별도 자막 트랙을 보존하고 로고나 추가 그래픽 편집에 관여하지 않습니다.
