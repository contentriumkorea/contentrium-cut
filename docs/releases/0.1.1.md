# Contentrium CUT

- Premiere 패널 안에서 트랙·화자·싱크·컷 설정과 검토를 제어하도록 개편했습니다.
- 선택한 영상은 최상단 **Contentrium CUT** 트랙에 수정 가능한 개별 컷으로 정리합니다. 원본 시퀀스와 기존 오디오·자막·그래픽 데이터는 보존하며 로고 배치는 사용자가 편집합니다.
- 업데이트 클릭 즉시 새 CUT 작업을 차단하고 중단 요청을 보냅니다. 미리보기 종료나 GitHub 재확인이 업데이트 시작을 막던 문제를 수정했습니다.
- 느린 원본 검증·모델 준비·캐시 정리 중에도 취소와 상태 확인을 처리하고, 응답 유실·프로세스 중단 후에는 작업 기록을 확인하도록 보완했습니다.
- 분석 실행 중 별도 콘솔 창이 나타날 수 있는 실행 옵션을 수정했습니다.

다운로드와 검증 후 Premiere를 정상 종료하면 플러그인을 교체합니다. 프로젝트를 강제로 닫지 않습니다. 업데이트 정보는 Ed25519로 서명하고 배포 파일의 SHA-256을 검증합니다.

이번 공개의 검증 범위와 미실행 항목은 [검수 기록](https://github.com/contentriumkorea/contentrium-cut/blob/main/docs/qa/2026-10-06-update-responsiveness.md)에 명시합니다. 실제 설치된 새 패널의 Premiere 동작과 Community-1 실음성 품질은 아직 검증하지 않았습니다. 원래 0.1.0의 설치 검증 결함으로 기존 설치의 전환에는 [소스 보조 전환](https://github.com/contentriumkorea/contentrium-cut/blob/main/docs/source-assisted-migration.md)이 필요합니다. 이 공개를 원래 0.1.0 자동 업데이트의 실기 통과로 보지 않습니다.
