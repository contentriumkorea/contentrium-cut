# Contentrium CUT

- 컷 검토 목록에 원본 시작·종료 프레임과 컷 길이를 추가했습니다. 같은 초 안의 인접 컷도 구별할 수 있습니다.
- 컷 길이는 실제 시퀀스의 유리수 FPS로 계산하며 시퀀스 헤더에 정확한 FPS 비율을 표시합니다.
- 검색에서 카메라·선택 이유뿐 아니라 표시된 프레임 범위와 길이도 찾을 수 있습니다. 검색은 전체 편집안과 Premiere 이동 프레임을 변경하지 않습니다.
- 프레임 표시는 0부터 시작하며 종료 프레임은 다음 구간의 시작 경계입니다. 시간은 경과 시간이며 소스 타임코드나 Drop-frame 타임코드가 아닙니다.

단일 Premiere 패널, 최상단의 수정 가능한 개별 컷, 원본과 별도 자막 트랙 보존 계약을 유지합니다. 업데이트 클릭 즉시 작업 차단·중단 요청·업데이트 절차 시작을 유지하며 파일 교체는 Premiere 정상 종료 뒤 진행합니다.

사용자 PC에는 재설치하지 않았습니다. 설치된 새 UXP 화면·Premiere 편집 결과·기존 설치의 실제 전환과 Community-1 실음성 품질은 아직 미검증입니다. [반복 개선 기록](https://github.com/contentriumkorea/contentrium-cut/blob/main/docs/qa/continuous-improvement.md)에서 실행 범위를 확인할 수 있습니다.
