# Contentrium CUT

편집 범위를 잘못 입력해도 연결된 시퀀스와 마이크·카메라 설정을 유지하며 바로 고칠 수 있습니다. 빈 값, 정수가 아닌 프레임, 역전된 범위, 타임라인 끝을 넘은 범위는 패널에 안내하고 분석·싱크·편집 적용을 차단합니다.

입력 중에도 이전 분석과 편집안을 무효화합니다. 설정 저장·복구와 자동 타임라인 갱신에서도 입력한 값을 유지하며, 기존 설정 파일의 숫자 범위도 계속 읽습니다. 실제 프로젝트/시퀀스 닫힘 처리와 업데이트 클릭 즉시 작업 차단은 유지합니다.

패널 핸들러·전체 회귀·독립 소스 검수, 패키지 실행과 공개 업데이트 서명·다운로드 해시를 검증합니다. 컴퓨터유즈와 PC 재설치를 수행하지 않았으며 실제 Premiere/UXP 화면·편집·기존 설치 전환·Community-1 품질은 미검증입니다.
